# ISO/IEC 27001:2022 Gap Assessment

## When to use
- "ISO 27001", "ISMS gap", "Annex A"
- Pre-certification readiness for Naga Codex clients

## Scope
High-level control themes (not a full Stage 1/2 audit):
- Organizational controls (policies, roles, asset mgmt, supplier)
- People controls (screening, training, remote work)
- Physical controls (if in scope)
- Technological controls (access, crypto, logging, malware, backup, network, secure dev)

## Workflow
1. Confirm ISMS scope (org units, systems, locations)
2. Interview + evidence sampling (policies, tickets, configs)
3. Rate each theme: conform / partial / gap
4. Link technical findings from other skills into Annex A themes
5. Roadmap to certification readiness (documentation vs implementation)

## Output
Gap register with Annex A theme, evidence, priority, owner suggestion.

## Note
Certification requires accredited bodies. This skill prepares — it does not certify.
